# Туман СПб

PWA с почасовой вероятностью тумана по данным [Open-Meteo](https://open-meteo.com) (без ключа и без бэкенда).

## Запуск

```bash
npm install
npm run dev        # разработка (сервис-воркер отключён)
npm run build      # typecheck + сборка приложения + dist/sw.js
npm run preview    # прод-сборка на http://localhost:4173 (и в локальной сети: --host)
```

Чтобы поставить на телефон, `dist/` нужно выложить на HTTPS (GitHub Pages, Netlify, Cloudflare Pages —
подойдёт любой статический хостинг, пути относительные). Затем в браузере телефона: «Установить
приложение» (Android) или «Поделиться → На экран „Домой“» (iOS).

## Как устроено

- `src/lib/fog.ts` — формула fog score (0–100), уровни, тип тумана, окна риска.
- `src/lib/api.ts` — запрос к Open-Meteo (`wind_speed_unit=ms`, `timezone=auto`, 3 дня → 48 ч вперёд).
- `src/lib/db.ts` — IndexedDB: последний прогноз (офлайн), координаты, отметка об уведомлении.
- `src/lib/notify.ts` — уведомление, когда в ближайшие 12 ч вероятность ≥ 55%; одно окно — одно уведомление.
- `src/sw/sw.ts` — сервис-воркер: офлайн-оболочка, кэш шрифтов, фоновая проверка (Periodic Background Sync).
- `scripts/gen-icons.mjs` — генерация иконок (`npm run icons`).

## Ограничения

- Без сервера нет настоящего push: уведомления приходят при открытии приложения, а на Android
  у установленного PWA ещё и через Periodic Background Sync (частоту определяет браузер).
- На iOS уведомления работают только у приложения, добавленного на экран «Домой» (iOS 16.4+).
- «Ветер с залива» (200–280°) откалиброван для центра Петербурга.
- Оценка эвристическая, это не официальный прогноз.
