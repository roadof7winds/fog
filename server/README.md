# Сервер рассылки

Cloudflare Worker: раз в час просыпается, смотрит, у кого из подписчиков наступило окно доставки
(вечер 20:00–24:00, утро 7:00–9:00 по их местному времени), считает прогноз **той же моделью, что и
приложение** — включая ансамбль из шести моделей погоды и поправку на факт Пулково — и шлёт push.

Зачем: без сервера уведомление приходит, только когда приложение открыто или браузер сам разбудил
фоновую проверку. На iPhone такой проверки нет вовсе.

## Что хранится

Только адрес подписки, координаты, округлённые до сотых (примерно километр), и часовой пояс.
Ни имени, ни истории, ни точного места.

## Развёртывание

Нужен бесплатный аккаунт Cloudflare.

```bash
cd server
npm install
npx wrangler login                      # откроет браузер

npx wrangler kv namespace create SUBS   # выведет id — вписать в wrangler.toml
npx wrangler secret put VAPID_PRIVATE_KEY   # вставить приватный ключ (он не в репозитории)

npx wrangler deploy
```

После деплоя команда напечатает адрес вида `https://fog-push.<аккаунт>.workers.dev`. Его нужно
положить в переменную репозитория `PUSH_URL` (Settings → Secrets and variables → Actions →
Variables), и при следующей сборке в приложении появится кнопка рассылки.

Проверить, что воркер жив: `curl https://fog-push.<аккаунт>.workers.dev/health` → `{"ok":true}`.
Посмотреть, что он делает: `npx wrangler tail`.
Отправить проверочный запуск расписания: `npx wrangler dev --test-scheduled`, затем
`curl "http://localhost:8787/__scheduled"`.

## Ключи VAPID

Открытый ключ лежит в `wrangler.toml` и в `src/lib/push.ts` — он и должен быть публичным.
Приватный хранится только как секрет воркера. Если его потерять, подписки придётся оформлять заново:
сгенерировать новую пару и заменить открытый ключ в обоих местах.
